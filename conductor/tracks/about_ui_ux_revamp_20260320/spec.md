# Specification: About Page UI/UX Revamp

## Objective
Revise the "About" page (`pages/about.html`) to drastically improve the UX and UI, mirroring the professional polish and "Modern & Airy" feel established on the homepage.

## Scope
- **Page Introduction:** Implement a "Clean Typography" header. Use large, bold typography for the page title on a clean, white background to set a clear, professional tone.
- **Professional Story:** Refactor the bio content into an "Airy & Centered" layout. Move away from the basic split-section to a layout that prioritizes focus and readability with generous whitespace and centered text elements.
- **Refined Photo Gallery:** Upgrade the `photo-grid` using "Refined Cards." Apply rounded corners, subtle shadows, and scaling hover effects consistent with the employer logo grid on the homepage. Ensure captions are well-integrated and professionally styled.
- **Closing CTAs:** Add a prominent call-to-action section at the bottom of the page featuring "View Resume," "Contact Me," and "View References" buttons to guide users toward the next professional step.

## Non-Goals
- Changing the established brand colors or typography fonts defined in the Tailwind config.
- Rewriting the core bio text (focus is on presentation and UX).
