# Product Guidelines: Professional Portfolio Website

## 1. Prose & Voice
* **Tone:** Professional, approachable, and confident. Avoid overly technical jargon unless necessary for specific project descriptions.
* **Clarity:** Prioritize clear and concise communication. Use active voice and bullet points for readability.
* **Accuracy:** Ensure all information, especially in the resume and portfolio, is accurate and up-to-date.

## 2. Branding & Visual Identity
* **Consistency:** Maintain a consistent **Modern & Airy** visual identity across all pages, emphasizing generous whitespace, centered layouts for storytelling, clean typography, and professional card-based components with subtle interactive feedback.
* **Imagery:** Use high-quality, professional photographs and graphics that align with the site's professional image.
* **Logo & Favicon:** Use established brand elements (logo, favicon) consistently.

## 3. User Experience (UX) & Design
* **Responsive Design:** Ensure the website is fully responsive and functions perfectly on all devices (mobile, tablet, desktop).
* **Navigation:** Provide simple and intuitive navigation. Visitors should be able to find key information easily.
* **Performance:** Optimize images and code to ensure fast loading times.
* **Accessibility:** Adhere to basic accessibility standards (e.g., alt text for images, clear contrast) to ensure the site is usable by all.

## 4. Content Strategy
* **Value-First:** Focus on providing value to the target audience (employers and clients).
* **Call to Action:** Include clear and compelling calls to action (e.g., "Contact Me," "View Portfolio").
