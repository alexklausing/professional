# Tech Stack: Professional Portfolio Website

## 1. Frontend Technologies
* **HTML5:** For structured web content.
* **JavaScript:** For client-side interactivity and dynamic features.
* **Tailwind CSS:** For utility-first styling and a modern, responsive UI.

## 2. Infrastructure & Deployment
* **GitHub Pages:** For hosting and deploying the static website directly from the repository.

## 3. Development Tools
* **Browser-sync:** For real-time browser reloading during development.
* **npm-run-all:** For running multiple scripts in parallel.
* **Tailwind CLI:** For building and minifying CSS.
* **Docker:** (Optional) For containerized local development.
